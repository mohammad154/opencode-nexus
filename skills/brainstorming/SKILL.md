# Brainstorming

Before planning:

1. Restate user goal in plain language.
2. Identify technical constraints and trade-offs.
3. Ask focused clarifying questions if needed.
4. Define success criteria and non-goals.
5. Propose a preferred approach with rationale.

Output must include:

- Problem framing
- Suggested implementation direction
- Risks and mitigations
- Clear handoff into `writing-plans`
